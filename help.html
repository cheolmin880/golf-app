함께 보기

모든 게임은 방 코드로 연결됩니다. 한 사람이 방을 만들고 코드를 알려주면, 나머지는 그 코드로 들어와 같은 화면을 봅니다.

누가 점수를 넣든 모두의 화면이 즉시 바뀝니다.

6-ROUND GAME
⛳ 6라운드 게임
18홀을 6홀씩 3라운드로 나눠
라운드마다 순위를 매기고 정산합니다.
진행 방법
1
방 만들기 → 3자리 코드가 나옵니다
2
동반자에게 코드를 알려주고 참가하기로 들어오게 합니다
3
▶시작을 눌러 이름·핸디·금액을 정합니다
4
홀마다 칸을 눌러 파 대비 타수를 고릅니다
5
18홀이 끝나면 결과 탭에서 정산을 확인합니다
라운드별 핸디 조정

6홀이 끝날 때마다 순위에 따라 다음 라운드 핸디가 바뀝니다. 1등은 1타 줄고, 꼴찌는 1타 늘어납니다.

실력 차가 나도 뒤로 갈수록 팽팽해지는 게 이 게임의 재미입니다.

버디·이글 벌금

버디를 하면 나머지 전원이 정해진 금액을 냅니다. 이글은 별도로 더 큰 금액을 설정할 수 있습니다.

🔂 라운드당 1회 ♾️ 제한 없음
멀리건 버디

멀리건을 치고 버디를 했다면 🔄 멀리건버디를 고르세요.

스코어는 버디(-1)로 인정되지만 벌금은 면제됩니다. 점수판에는 "멀리건 -1"로 표시됩니다.

5명까지 가능합니다. 설정 맨 위에서 참가 인원을 고르면 입력칸과 금액표가 함께 바뀝니다.
STROKE GAME
📊 스트로크 게임
18홀 총타수에 핸디를 빼서
넷스코어로 순위를 정합니다.
진행 방법
1
방 만들기 후 코드를 공유합니다
2
▶시작에서 이름·핸디·1타 금액을 정합니다
3
홀마다 타수를 입력합니다
4
📊결과에서 순위와 주고받을 금액을 봅니다
계산 방식

넷스코어 = 총타수 − 핸디캡

넷스코어 차이만큼 1타 금액을 곱해 정산합니다. 1타에 5만 루피아, 3타 차이면 15만 루피아입니다.

배판을 설정하면 꼴찌가 배수로 물게 됩니다. 판을 키우고 싶을 때 쓰세요.
SCORECARD
📋 스코어카드
돈 계산 없이 성적만 기록합니다.
전반·후반을 나눠 보는 전통 방식입니다.
진행 방법
1
⚙️에서 코스명·스타트홀·홀별 파를 정합니다
2

4
전반이 끝나면 후반 →으로 넘어갑니다
홀별 파 설정

파는 실제 홀 번호 기준으로 넣습니다. 스타트홀이 10번이어도 파 설정은 1번홀부터 순서대로 입력하세요.

숫자를 누를 때마다 P3 → P4 → P5로 바뀝니다.

스타트홀을 바꾸면 화면에 보이는 홀 순서만 바뀝니다. 파 설정은 그대로 유지되니 다시 만질 필요 없습니다.

🏆 대회 시상
여러 조가 참가하는 단체 대회용입니다.
조별 성적을 모아 시상자를 정합니다.

모든 조의 성적과 시상을 관리합니다
🏌️
조장참여하기 → 코드 입력 → 자기 조 선택
맡은 조의 성적만 입력합니다
👀
참가자참여하기 → 코드 입력 → 참가자로 보기
전체 순위를 실시간으로 봅니다
참가자도 조장과 같은 "참여하기"로 들어옵니다. 코드를 넣으면 역할 선택 화면이 나오니 맨 위 참가자로 보기를 누르면 됩니다.
진행 순서
1
진행자가 대회를 만들고 이름·날짜·파3/파5 홀을 정합니다
2
조를 추가하고 각 조 조장을 지정합니다
3
시상 설정에서 줄 상과 상금을 정합니다
4
조장들이 성적을 입력합니다
5
시상 결과에서 순서대로 발표합니다
성적 입력 두 가지 방법

간단히 — 전반·후반 또는 총타수만 직접 입력

자세히 — 18홀 성적입력 버튼으로 홀마다 기록. 입력하면 합계가 자동 계산되고 버디·이글에 축하 연출이 나옵니다.

오버타가 핵심입니다

오버타 = (총타수 − 코스파) − 핸디

이 숫자 하나로 핸디 대비 누가 잘 쳤는지 바로 드러납니다. 작을수록 좋습니다.

선수핸디타수오버타
고수580+3
중수1588+1 ←
초보28105+5

타수는 고수가 가장 낮지만, 핸디를 감안하면 중수가 제일 잘 쳤습니다.

중복 수상 처리

한 사람이 두 상을 받게 되면 상금이 큰 상이 먼저 배정되고, 밀린 상은 다음 순위로 넘어갑니다.

상금이 같으면 시상 순서상 뒤쪽(더 무거운 상)이 가져갑니다.

핸디 부문별 시상을 켜면 로우·하이 핸디부를 나눠 각각 1위를 뽑습니다. 기준 핸디를 정하면 인원이 바로 표시됩니다.

저장은 어떻게 되나요?

💾저장을 누르면 앱 안에 보관됩니다. 파일이 다운로드되지 않으니 걱정하지 마세요.

📂불러오기에서 지난 기록을 다시 열 수 있고, 필요하면 📤로 파일을 빼낼 수도 있습니다.

입력하는 즉시 자동으로도 저장되니, 실수로 앱을 닫아도 그대로 남아 있습니다.

축하 연출

버디 이상을 넣으면 화면 가득 축하가 나옵니다.

🐦 버디 −1 🦅 이글 −2 🦅 알바트로스 −3

색종이와 팡파레가 함께 나오며, 등급이 높을수록 화려해집니다. 조용히 해야 할 때는 🔊를 눌러 끄세요.
